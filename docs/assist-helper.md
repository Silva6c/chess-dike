# 连线功能说明（屏幕识别 · 悬浮窗走法指导）

## 功能定位

本功能是"象棋迪克"（开源免费安卓版中国象棋学习工具）的连线模块，参考了桌面端象棋连线器
（VinXiangQi 及其衍生 XiangQiLink）的思路，把"屏幕识别 → 引擎分析 → 提示建议"搬到 Android 上：

1. 用系统录屏授权（MediaProjection）只读截取当前屏幕画面；
2. 用 **YOLOv5 深度学习模型**直接检测画面中的棋子（14 类棋子 + 整体棋盘框），
   自动得到 9×10 棋盘局面——**免校准、免采集**，兼容天天象棋 / JJ 象棋 / 自研棋盘等不同画风；
3. 自动判定**靠近玩家一侧（屏幕下方阵营）就是我方**，并识别我方执红还是执黑（含换边局）；
4. 复用项目内嵌的 pikafish 引擎对当前局面进行分析；
5. 在**悬浮窗**中显示：**原版样式的微缩棋盘**（与主界面同一套棋盘/棋子图，随被识别屏幕的朝向显示，
   底部永远是我方一侧）、我方最佳走法（如"炮二平五 (h2e2)"）以箭头标注在迷你棋盘上、
   红/黑优劣势与深度、候选着法与变着；
6. **悔棋**：点"悔棋"可回退到上一个已确认局面重新分析（看上一手之前的建议），
   再点"继续"恢复实时识别；**引擎强度**：点"深度"在 深度12（快速）/ 深度20（标准，默认）/ 深度24（强劲）
   三档间循环，档位会记住。

识别只服务于"我方"：**靠近玩家的一侧给建议**；对方回合引擎的算力同样为我方所用——
展示"若对方走X，我方应Y"的应对预案（箭头画我方应手），我方走子确认后立即转入新局面计算。
引擎不做（也不需要做）任何干扰对方的操作。

## 为什么它不是外挂（合规说明）

本项目是大作业/学习用途，明确不做任何作弊功能，也刻意避免"外挂特征"：

| 本项目 | 拒绝的做法（典型外挂特征） |
| --- | --- |
| 只通过系统出屏授权"看"画面 | 触摸/手势注入（AccessibilityService dispatchGesture、注入 MotionEvent） |
| 只显示建议文本与箭头，走子由玩家手动完成 | 自动点击、自动走子、自瞄 |
| 仅申请 SYSTEM_ALERT_WINDOW 悬浮窗与录屏两个常规权限 | 无障碍服务、Root/Xposed/注入插件、读写他人 App 内存与文件 |
| 识别结果经"稳定帧校验+合法性校验+迷你棋盘回显"保证正确 | 实时屏下"注入式"操作，无用户可核对依据 |

权限一览：`SYSTEM_ALERT_WINDOW`（悬浮窗，与微信/输入法同类）、
`FOREGROUND_SERVICE` + `FOREGROUND_SERVICE_MEDIA_PROJECTION`（录屏式前台服务）、
`POST_NOTIFICATIONS`（前台服务通知）。**未申请** `BIND_ACCESSIBILITY_SERVICE`、`QUERY_ALL_PACKAGES` 等敏感权限。

## 首次使用步骤（真机验证清单）

1. 首页 → **连线** → 进入功能页；
2. ① 在弹出的系统设置中允许悬浮窗权限；② 允许通知（Android 13+）；
3. ③ 点击"开始屏幕识别"，在系统录屏授权对话框选"开始录制/立即开始"（Android 14 需再次确认）；
4. 切到任意象棋 App 的对局界面即可——**YOLO 识别全自动**：自动找棋盘、自动判定朝向
   （红上/红下）、自动开始识别。悬浮窗出现在屏幕底部（不遮挡棋盘），显示迷你棋盘与建议；
5. 常用按钮：状态栏大字（建议/优劣势/轮次信息，一眼可读）、左下一行 **变招**（切换候选着法，
   点迷你棋盘同效）、**悔棋**（回退一步，点"继续"恢复实时）、**手动**（紧急手动模式，见下）；
   右列 **深度**（引擎思考深度三档：12 快速 / 20 标准=对弈默认 / 24 强劲）、**Hash**（引擎置换表
   大小，从 256MB 起循环 256→512→1024→2048，对下一次搜索生效）、**更新棋局**（显示的
   行棋方与实际不符时点一下立即纠正）、**停止**、**关闭**（需二次确认：先变“确认关闭?”，
   3 秒内再点才真正关闭，误触有缓冲）。
   我方颜色自动判定（屏幕下方阵营=我方），无需手动切换。

## 紧急手动模式（识别失效时的兜底）

个别对局界面（如某些残局/特殊皮肤）识别可能临时失效——状态栏持续显示“正在识别棋盘…”或
迷你棋盘出现明显错子。此时点 **手动** 进入紧急手动模式：自动识别暂停，由你在迷你棋盘上手工
维护局面，引擎/开局库继续给建议：

- **录入着法**：点我方或对方的子（金色高亮）→ 点目标格，等同实战走了一步，行棋方自动翻转；
- **删子**：点一下已选中的子再点它自己，即从盘面删除（用于清除“幻影棋子”；帅/将不可删）；
- **悔棋**可逐步撤销手工编辑；**更新棋局**可纠正行棋方；**变招/深度**照常可用；
- 再点一次 **手动** 即恢复自动识别（识别恢复后会自动接手工局面继续跟踪）。

附注：识别全自动，悬浮窗与连线页均无"校准"按钮（手动校准系统已随本版本移除）；
识别模型内置于应用（约 3.8MB，随应用安装，无需联网）。

## 技术要点（答辩速览）

- **识别管线（YOLO 检测）**：屏幕帧 letterbox 到 640×640 RGB → TFLite 运行 YOLOv5n
  （15 类：14 种棋子 + 棋盘框）→ 解码 + 类别感知 NMS → 置信度/宽高比/尺寸一致性过滤
  （排除工具栏按钮、"轮到谁"标记盘等误检）→ 棋盘框宽/8、高/9 得到格距，棋子中心
  round 到最近交叉点 → 帅/将位置判屏幕朝向（红在下/红在上）→ 镜像映射到内部"红恒在下"坐标系
  → 数量/将帅/上限合法性校验；
  解码、过滤与棋盘映射为纯 JVM 实现（`YoloPostprocessor` / `DetectionBoardMapper`），可单测；
- **稳定性**：连续 N 帧（默认 3）识别结果一致才确认新局；动画/选中态造成的跳动帧被丢弃；
  新对局（回到开局）自动重置轮次；已知棋盘位置后裁剪推理，若棋盘挪动导致残框内长时间
  不稳定会自动回退全屏重新定位；
- **我方颜色判定**：屏幕下方阵营＝我方；下方是红→我方执红，下方是黑（换边局）→我方执黑，
  完全自动（迷你棋盘朝向随动，底部恒为我方一侧）；
- **轮次(w/b)推断**：通过新旧局面对比出"刚走子的阵营"自动翻面（支持吃子）；
- **开局库**：与对弈功能同款"桔库"（247 万条实战着法）。我方回合先查库，命中直接给出
  库内着法（含胜/和/负战绩，绿✓，零等待），未命中才走引擎——开局阶段建议即时且正统；
- **引擎**：独立启动一个 pikafish UCI 进程（复用项目内嵌二进制与 NNUE 权重），
  完成 `uci → uciok / isready → readyok` 握手后，按当前深度档发送
  `position fen + go depth 12/20/24`（与对弈"固定深度"同制式，默认 20），解析
  `info … score cp/mate … pv` 与 `bestmove`，3 路 MultiPV；线程=全部核心、Hash 可在面板上调节（默认 256MB）
  与对弈一致；与游戏内引擎互不影响；启动失败自动重试一次，仍失败会在悬浮窗与通知栏
  显示具体原因（重新进入连线即可重试）；
- **悔棋**：服务端维护确认局面历史（上限 60 步），"悔棋"回退一步并暂停实时同步，
  "继续"恢复后自动与屏幕重新对齐；纯本地状态回退，不操作对弈 App；
- **悬浮窗**：始终使用 `TYPE_APPLICATION_OVERLAY`，可拖动、位置记忆；
  状态文字与按钮分列迷你棋盘左右两侧（面板高度只由棋盘决定，尽量少占屏幕高度）；
  迷你棋盘为**原版微缩样式**（共用主界面 chessboard.png 与 14 张棋子图，箭头复用主界面 ArrowShape），
  朝向**随动**（被识别 App 红在上时迷你棋盘也红在上，底部恒为我方侧），
  红/黑色条指示我方所在侧；点击迷你棋盘=切换候选着法（变招，引擎每次给出前 3 条候选）；
  我方回合显示"建议 X"+箭头：**蓝=暂定（仍在计算）→ 绿 ✓=定着（最佳着法已 1.2 秒未变或搜索结束）**；
  对方回合不画箭头，仅文字给出"若对方走X 我方应Y"的应对预案（对方未走时画我方应手会产生
  "我方吃我方"的误导）；识别中断/不稳定期间旧建议自动隐藏，恢复后重现。
- **性能**：抓帧 220ms/识别 250ms 节流 + 已知棋盘位置后只裁棋盘邻域推理（YOLOv5n fp16，约 3.8MB）；
  面板仅在实际遮挡棋盘时才放慢抓帧以防闪烁。

## 识别模型来源与版权

- 检测模型基于 [VinXiangQi](https://github.com/Vincentzyx/VinXiangQi)（GPL-3.0）发布并提供训练的
  中国象棋 YOLOv5 权重（当前发货为其"小模型"YOLOv5n，覆盖天天象棋/JJ 象棋/QQ 象棋等主流画风），
  经 ONNX → TensorFlow Lite（fp16）格式转换后内置于应用 assets（`yolov5n_xq_fp16.tflite`）；
  模型版权归 VinXiangQi 项目所有，本项目（课程作业）同样以学习目的引用并保留此声明；
- 转换与验证工具链：onnx2tf + TensorFlow Lite Converter（转换脚本与验证样本见开发交接文档）。

## 已知限制

- 竖屏布局假设：默认竖向截屏（市面象棋 App 基本竖屏）；横屏/旋转后识别会暂停并提示；
- 单步走子确认约需连续 3 帧稳定识别（主流机型约 1 秒级）；对局动画期间不确认；
- 引擎二进制仅含 arm64：x86_64 模拟器上无法启动分析引擎（悬浮窗会提示"引擎异常"），
  真机不受影响；
- 不做（也不打算做）任何自动点击/自动走子。
