象棋迪克 · 使用说明

连线（AI 屏幕识别指导）

  • ① 授予悬浮窗 → ② 允许通知 → ③ 授权录屏并启动；
  • 切到任意象棋 App 对局界面即可：ONNX 角点式（主力）或 YOLO 自动找棋盘、自动识别朝向，悬浮窗实时给出我方建议；
  • 面板按钮：变招（切换候选）、N变（MultiPV 路数 1-3 循环，默认 1 路=算力最全；多路附带备选但同深度变慢）、悔棋（回退一步）、手动（识别失效时在小棋盘上手工维护局面）、 深度（深度制，12/20/24 三档）或时间（时间制，1-30 秒档，按连线页思考制式二选一显示）、哈希（引擎置换表大小，从 256MB 起循环调节）、引擎（ONNX/YOLO 热切换）、 更新（纠正行棋方）、闪电（打断当前搜索，立即采纳当前最优）、停止/关闭（关闭需二次确认）；
  • 连线页可热切换识别引擎（ONNX 角点式 / YOLO 检测式）、思考制式（深度制/时间制，悬浮窗只显示对应切换档）与悬浮窗主题（深色玻璃/纯黑 OLED/浅色纸感）；
  • 点击迷你棋盘可切换候选着法；建议成熟显示绿色箭头，暂定为蓝色。
  • 性能诊断（连线页设置区）：感觉识别变慢时打开，应用在系统 Download 目录 新建 XQDK_诊断_*.md 并标明位置，持续记录会话参数、事件（引擎加载/切换/自愈/ 棋盘确认）、每帧识别的分段耗时与节拍、引擎搜索推进，并周期汇总统计（成功/ 失败、平均/P50/P95）；关闭开关或退出连线时自动收尾，把该文件发回即可定位瓶颈。
  • 检查更新（连线页设置区）：手动点击查询 GitHub 正式版（不自动检查）； 发现新版本会弹窗并可跳转下载页。查询需要可访问 GitHub 的网络环境，失败会提示原因。
