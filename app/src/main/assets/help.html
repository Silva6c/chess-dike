象棋迪克 · 使用说明

开局分流

  • 打开应用进入分流页：点击学习模式（人机对弈+走子纠正教学）或连线模式 （屏幕识别+悬浮窗指导）进入对应功能；帮助与关于入口也在本页。

学习模式（人机对弈 · 走子纠正教学）

  • 应用内棋盘与皮卡鱼对弈，执红/黑任选（底部芯片切换，切换即开新局）；
  • 平时不给任何建议：你走一步，引擎立刻评估——优解（相对上一手评估损失 ≤ 0.8 兵）放行并显示我方分值，皮卡鱼随即应对；
  • 坏棋纠正：皮卡鱼亮出红色应着（悬浮箭头+红光效）→ 你的棋子退回原位、落点 以半透明幽灵棋子+灰虚线框标记 → 三解绿色指导（悬浮箭头+绿光效）与负分， 等待你更正；更正后重新应对；
  • 执迷不悟：把刚被撤回的同一着再走一遍 → 放行，皮卡鱼复用红箭头那着应对； 三条绿箭头按推荐度分三档严格深浅（最深=首推）；
  • 箭头深浅即优先级：三条绿箭头颜色最深的为引擎首推，越浅越靠后； 红箭头在等待更正期间淡化变细，退为"执迷不改就会挨的着法"预告；
  • 界面仅含：开新局 / 悔棋 / 执方切换 / 走势曲线（我方视角评估分折线，均势为中线）； 将军、将杀、困毙自动判定胜负；
  • 进度自动保存：退出学习模式时当前对局自动存档，下次进入自动恢复（盘面、 走势、悔棋链与终局结果都保留）；
  • 双引擎互斥：进入学习模式会自动停止连线识别，回分流页可重进连线。

连线（AI 屏幕识别指导）

  • ① 授予悬浮窗 → ② 允许通知 → ③ 授权录屏并启动；
  • 切到任意象棋 App 对局界面即可：ONNX 角点式（主力）或 YOLO 自动找棋盘、自动识别朝向，悬浮窗实时给出我方建议；
  • 面板按钮：变招（切换候选）、N变（MultiPV 路数 1-3 循环，默认 1 路=算力最全；多路附带备选但同深度变慢）、悔棋（回退一步）、手动（识别失效时在小棋盘上手工维护局面）、 深度（深度制，12/20/24 三档）或时间（时间制，1-30 秒档，按连线页思考制式二选一显示）、哈希（引擎置换表大小，从 256MB 起循环调节）、引擎（ONNX/YOLO 热切换）、 更新（纠正行棋方）、闪电（打断当前搜索，立即采纳当前最优）、停止/关闭（关闭需二次确认）；
  • 连线页可热切换识别引擎（ONNX 角点式 / YOLO 检测式）、思考制式（深度制/时间制，悬浮窗只显示对应切换档），悬浮窗主题（深色玻璃/纯黑 OLED/浅色纸感）在思考制式下方切换；
  • 点击迷你棋盘可切换候选着法；建议成熟显示绿色箭头，暂定为蓝色。
  • 性能诊断（连线页设置区）：感觉识别变慢时打开，应用在系统 Download 目录 新建 XQDK_诊断_*.md 并标明位置，持续记录会话参数、事件（引擎加载/切换/自愈/ 棋盘确认）、每帧识别的分段耗时与节拍、引擎搜索推进，并周期汇总统计（成功/ 失败、平均/P50/P95）；关闭开关或退出连线时自动收尾，把该文件发回即可定位瓶颈。
  • 空闲预计算（β 测试版，连线页设置区开关，默认开）：对方思考时引擎提前 计算当前局面，对方落子命中预判线时我方建议瞬间显示（带"预判β"标记）； 发热明显可关闭，关闭后回落常规行为；
  • 单次三变：3 秒内连点两下迷你棋盘，当前局面临时按 3 路重新分析一次， 三条候选可切换；常规变招档不变，下一局面自动回落；
  • 检查更新（分流落地页版本页脚）：手动点击查询 GitHub 正式版（不自动检查）； 发现新版本会弹窗并可跳转下载页。查询需要可访问 GitHub 的网络环境，失败会提示原因。
